# 宝塔部署分步操作清单（Debian 12 + 宝塔 + Nginx + MySQL 5.7 + PM2）

## 一、服务器准备（宝塔面板）
1. 软件商店安装：Nginx、MySQL 5.7.44、PM2 管理器、Node.js 版本管理器
2. Node.js 版本管理器里安装 Node 20 LTS（或 22 LTS），命令行版本切换到它
   - 验证：`node -v` ≥ v20.9
3. 安全组 / 防火墙放行：80、443；**不要放行 3000**（只走本机反代）

## 二、建库建表
4. 宝塔 → 数据库 → 添加数据库：
   - 数据库名：`health_cert`，字符集选 `utf8mb4`，创建一个专用用户（如 `health`）并设强密码
5. 终端执行建表（按顺序）：
   ```bash
   mysql -uhealth -p health_cert < db/mysql_schema.sql
   mysql -uhealth -p health_cert < db/mysql_seed.sql
   ```
6. 验证：`mysql -uhealth -p -e "SHOW TABLES FROM health_cert;"`
   - 应看到 `users card_keys region_units certs cert_seqs` 共 5 张表

## 三、传代码、装依赖、配环境
7. 把项目传到 `/www/wwwroot/health-cert`（git clone 或上传解压）
8. 复制环境模板并填写：
   ```bash
   cd /www/wwwroot/health-cert
   cp .env.example .env.production
   ```
   必填：`DB_NAME/DB_USER/DB_PASSWORD`（第4步建的）、`JWT_SECRET`（64位随机串）、
   `ADMIN_PASSWORD`（一级后台密码）、`DOMAIN=https://你的域名`
   可选：`UPLOAD_DIR=/www/wwwroot/health-data/uploads`（建议填，照片与代码分离）
   可选：COS 四项（留空=图片存本地磁盘，一样可用）
9. 创建目录并授权：
   ```bash
   mkdir -p logs /www/wwwroot/health-data/uploads
   chown -R www:www /www/wwwroot/health-cert /www/wwwroot/health-data
   ```
10. 安装并构建（内存<2G 的机器先加 2G swap，否则 build 可能 OOM）：
    ```bash
    cd /www/wwwroot/health-cert && npm ci && npm run build
    ```

## 四、PM2 启动
11. 方式A（推荐）：PM2 管理器 → 添加项目 → 启动文件选 `ecosystem.config.js`
12. 方式B（命令行）：
    ```bash
    cd /www/wwwroot/health-cert && pm2 start ecosystem.config.js && pm2 save
    ```
13. 验证：`curl -s -o /dev/null -w "%{http_code}" http://127.0.0.1:3000/` 应返回 200

## 五、Nginx 反代 + HTTPS
14. 宝塔 → 网站 → 添加站点，域名填你的域名，根目录随意（反代不走静态目录）
15. 站点设置 → 反向代理 → 添加：目标 `http://127.0.0.1:3000`，或直接把
    `deploy/nginx.conf.example` 的内容粘到站点配置文件对应位置
16. SSL → 申请 Let's Encrypt 证书 → 开启「强制 HTTPS」
17. 浏览器访问 `https://你的域名`，走一遍：二级登录 → 生成卡密 → 办证 → 扫码验真

## 六、日常运维
18. 更新代码：
    ```bash
    cd /www/wwwroot/health-cert && git pull && npm ci && npm run build && pm2 restart health-cert
    ```
    **只 build 不 restart 跑的还是旧代码**
19. 备份：宝塔计划任务每天备份 `health_cert` 库 + `UPLOAD_DIR` 目录
20. 日志：`logs/pm2-err.log`（ecosystem 已配好）；Nginx 日志在站点设置里看
